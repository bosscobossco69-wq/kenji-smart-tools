What is JSON?

JSON (JavaScript Object Notation) is a plain-text format for storing and exchanging data. It is widely used by web APIs and configuration files. A JSON document is built from objects ({}), arrays ([]), strings, numbers, true, false and null.

JSON syntax rules

  • Property names and strings must use double quotes.
  • Items are separated by commas, and there must be no comma after the last item.
  • Comments are not allowed.
  • true, false and null are lowercase. undefined, NaN and Infinity do not exist in JSON.
  • Every opening brace or bracket needs a matching closing one.

When to format and when to minify

Formatted (pretty-printed) JSON is easier to read while debugging an API response, checking a configuration file or reviewing a data export. Minified JSON removes whitespace to keep the text compact for transfer or storage. Keep a readable copy when you are still editing the data.

Things to know before you rely on the output

This tool parses your JSON in the browser and writes it back out. That means a few details can change:

  • Numbers with more than about 15 significant digits may be rounded. If you work with very long IDs, keep them as strings.
  • If an object has the same key twice, only the last value is kept.
  • Keys that look like whole numbers, such as "10" and "2", may be reordered.

Keep a copy of the original if exact digits or ordering matter.

Frequently asked questions

Is my JSON uploaded?

No. Parsing and formatting happen in your browser and the input is not sent to our server.

What does Valid JSON mean here?

It means the text follows JSON syntax and can be parsed. It does not check the data against a schema or confirm that the values make sense for your application.

Does formatting change my data?

The values stay the same in most cases, but formatting parses and rewrites the JSON. Numbers with more than about 15 significant digits can be rounded, duplicate keys keep only the last value, and keys that look like whole numbers may be reordered. Keep a copy of the original if exact digits matter.

Why does my JSON show an error?

The most common causes are single quotes, a trailing comma, a comment, an unquoted key, or a missing comma or bracket. The tool reports the error and, where the browser provides it, the line and column.

What is the difference between JSON and a JavaScript object?

JSON is a text format with stricter rules. Keys and strings must use double quotes, and comments, trailing commas, undefined and functions are not allowed. A JavaScript object literal is more flexible.
