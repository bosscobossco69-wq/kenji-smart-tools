Format, validate, and minify JSON

Paste JSON into the input box and choose Format to make the structure easier to read, or Minify to remove unnecessary whitespace. The tool also reports whether the input is valid JSON.

When to format JSON

Pretty-printed JSON is easier to inspect while debugging APIs, configuration files, and data exports. Indentation makes nested objects and arrays easier to follow.

When to minify JSON

Minified JSON is useful when a compact representation is needed for transfer or storage. Keep a readable copy when you are editing data.

Frequently asked questions

Is my JSON uploaded?

No. Parsing and formatting happen in your browser; the input is not sent to our server.

Why does invalid JSON show an error?

JSON requires double-quoted property names and strings, valid commas, and matching braces and brackets. Check the reported error and correct the input before formatting.
