Password Generator

Create strong random passwords with a strength estimate. Generated in your browser and never sent anywhere.

    How to create a strong password

    1. Choose a length. This tool supports 4 to 128 characters.
    2. Select the character types you want. The password updates as you change the options.
    3. Copy the password straight into your password manager or the account you are setting up.

    The tool always includes at least one character from each type you select, and the characters are placed in a random order.

    What makes a password strong

    • Length: every extra character multiplies the number of possible passwords.
    • Randomness: a random password is much harder to guess than a word, a name or a date with a few changes.
    • Uniqueness: reusing a password means one data breach can expose all your accounts.

    How the strength estimate works

    The estimate is measured in bits. It is the password length multiplied by the base-2 logarithm of the number of possible characters. Each extra bit doubles the number of possible passwords. It assumes every character is chosen at random, so it is a rough guide, not a guarantee. Real-world security also depends on how a service stores your password and whether you reuse it.

    The tool labels results below 40 bits as weak, 40 to 59 as fair, 60 to 79 as strong and 80 or more as very strong. These labels are a simple guide.

    Look-alike characters and symbols

    By default the generator leaves out I, O, l, 0 and 1, because they are easy to confuse when you read or type a password by hand. Untick the option if you want every character. The symbols used are ! @ # $ % & * ?, a small set that most websites accept. If a site rejects your password, untick Symbols and use a longer password instead.

    Good habits for passwords

    • Use a different password for every account.
    • Store passwords in a trusted password manager instead of memorizing or reusing them.
    • Turn on two-factor authentication where it is available.
    • Do not share passwords in chats, emails or shared documents.
    • Generate passwords on a device you trust.

    Frequently asked questions

    What password length should I use?

    Many security guides recommend at least 12 to 16 characters, and longer for important accounts such as email, banking and your password manager. A unique password for every account matters as much as length.

    Are the passwords really random?

    Yes. They are created with your browser’s cryptographically secure random number generator, not with the predictable Math.random function. The tool also avoids the small bias that a simple remainder calculation can cause.

    Does KENJI store or send the passwords I generate?

    No. Passwords are generated in your browser and are not sent to our server. Copy the result into a trusted password manager and avoid saving it in shared documents or chats.

    Why are some characters missing, such as I, O, l, 0 and 1?

    By default the generator avoids look-alike characters that are easy to misread when you type a password by hand. You can untick the option to include them. This slightly increases the number of possible passwords.

    What does the strength estimate mean?

    It is based on the length and the number of possible characters, assuming every character is chosen at random. It is a rough guide and not a guarantee, because real security also depends on how the service stores your password and whether you reuse it.

    What if a website rejects my generated password?

    Some sites limit the length or the symbols they accept. Untick Symbols and use a longer password, or reduce the length to the limit the site allows.
