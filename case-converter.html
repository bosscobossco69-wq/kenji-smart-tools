Case Converter

Convert text between UPPERCASE, lowercase, Title Case, Sentence case and camelCase instantly.

How to use the case converter

Paste or type your text, then choose the format you need. The result replaces the text in the editor, so you can make another conversion or copy it into a document, email, title, or code editor.

  1. UPPERCASE: changes every letter to capital letters.
  2. lowercase: changes every letter to small letters.
  3. Title Case: capitalizes the first letter of each word.
  4. Sentence case: capitalizes the beginning of sentences.
  5. camelCase: removes separators and capitalizes the next word, useful for variable names.

Examples and common uses

Use uppercase for short labels, sentence case for readable notes, title case for headings, and camelCase for JavaScript-style variable names. For example, “customer account name” becomes “customerAccountName” in camelCase.

Frequently asked questions

Is my text uploaded?

No. Conversion happens in this page in your browser; the text is not sent to our server.

Does the converter change punctuation?

No. It changes letter casing and separators for camelCase; review the result before using it in code or published content.
